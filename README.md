# S1 Plus - Stage1st 体验增强套件

## 简介

S1 Plus 是一个面向 Stage1st（S1）的用户脚本，目标是让论坛浏览更清爽、更高效、更可控。
它提供帖子/用户/楼层屏蔽、用户标记、回复收藏、阅读进度跟踪、导航定制、自动签到，以及基于 GitHub Gist 的跨设备同步能力。

### 🔧 技术改进与重构

- 纯文本链接处理逻辑精简，降低主流程嵌套层级

## 核心功能总览

### 1) 帖子与楼层管理

- 列表页三点菜单快速屏蔽帖子，带二次确认
- 关键字 / 正则规则屏蔽标题
- 支持楼层级屏蔽（无需屏蔽整位用户）
- 可自动隐藏系统屏蔽楼层

### 2) 用户屏蔽与联动

- 帖内一键屏蔽用户，隐藏其回帖/评分/提醒相关内容
- 设置面板支持手动输入用户名屏蔽（自动识别 UID，可填写备注）
- 用户详情页顶部可直接屏蔽/解除屏蔽当前用户
- 可选同步到论坛原生黑名单
- “同步至论坛黑名单”提示中的“论坛黑名单”为可点击外链，支持一键打开论坛原生黑名单页
- 可按用户配置“是否联动屏蔽其主题帖”
- 屏蔽时可添加备注，便于后续识别

### 3) 用户标记系统

- 帖内直接标记用户，支持快捷编辑/删除
- 标记支持预设颜色
- 支持历史标记快速复用
- 设置面板集中管理，支持导入/导出

### 4) 回复收藏系统

- 帖内一键收藏回复
- 收藏面板支持检索、跳转、展开/折叠
- 同步时可选“仅预览（默认）”或“完整正文”

### 5) 阅读进度与浏览增强

- 自动记录帖子阅读位置（页码 + 楼层）
- 列表页提供快速跳转与新回复提示
- 支持自动清理或手动清理阅读记录
- 手动清理支持查看分组详情并按组删除
- 支持将常见 `http://` / `https://` / `www.` 纯文本链接自动转换为可点击链接
- 可单独配置“纯文本自动链接”是否新标签页打开，以及是否后台打开

### 6) 同步与数据安全

- GitHub Gist 云同步（跨设备）
- SHA-256 数据完整性校验
- 智能冲突判断与手动推送/拉取
- 跨标签同步锁、冲突冷却、失败熔断保护
- 同步诊断信息查看与复制（用于排错）

### 7) 界面与导航定制

- 导航链接增删改拖拽排序
- 链接打开行为与界面细节可定制
- 支持限制超大图片显示尺寸（默认 `800x1200`，可自定义）并由 S1 Plus 查看器统一接管点击查看
- 图片查看器工具条支持放大/缩小、上下滚动、完整显示与新标签打开原图；四个图标按钮支持长按连续操作
- 图片查看器关闭时自动恢复焦点，减少浏览器无障碍告警干扰
- 自动适配 S1 NUX 主题
- 搭配 S1 NUX 深色主题时，可自动修复少量帖子内联黑字导致的不可读问题（仅对异常文本生效）
- 在 NUX 顶栏头像展开区域补充“帖子”快捷入口，支持一键进入“我的帖子”列表
- 自动签到与常用浏览增强

## 快速上手

### 进入设置面板

- 在论坛导航栏点击 `S1 Plus 设置`
- 面板包含 7 个标签页：通用设置、帖子屏蔽、用户屏蔽、用户标记、回复收藏、导航栏定制、设置同步

### 开启云同步

1. 打开“设置同步”
2. 填写 Gist ID 与 GitHub Token
3. 按需调整同步相关开关（如自动后台同步、状态指示器等）
4. 点击“保存设置”使改动生效
5. 首次可先手动同步一次确认状态

> 说明：同步页中的配置项采用“手动保存”模式，修改后需点击“保存设置”才会真正写入并生效。

### 使用同步诊断

- 打开设置面板后，对底部版本号连续点击 3 次
- 可查看最近同步尝试/成功/失败/冲突信息
- 支持一键复制诊断信息，便于反馈问题

### 常用日常操作

- 屏蔽帖子：列表页三点菜单
- 屏蔽楼层：帖内工具栏“屏蔽楼层”按钮
- 标记用户：帖内工具栏“标记用户”按钮
- 收藏回复：帖内工具栏“收藏回复”按钮
- 手动同步：导航栏同步图标点击（或悬停高级模式）

## 常见问题

### Q1: 数据会丢吗？

默认保存在本地浏览器存储。启用云同步后，会额外备份到你的 GitHub Gist。

### Q2: 多设备阅读同一帖，进度会冲突吗？

6.3.0 已增强冲突判定与阅读进度自动合并策略，常见场景下可自动处理；若仍冲突，可通过手动同步选择保留版本。

### Q3: 同步失败怎么排查？

优先检查：Token 是否过期、Gist ID 是否正确、网络是否可访问 GitHub。
然后打开同步诊断（设置面板三连击版本号）查看失败原因。

### Q4: 为什么某些按钮没有出现？

请确认对应功能开关已开启，并检查脚本管理器内脚本是否已启用；若论坛页面结构变更，也可能导致按钮暂时失效。
